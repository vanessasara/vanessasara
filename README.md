I build **production-grade DevOps pipelines** and **agentic AI systems** — the kind of infrastructure that ships fast, observes itself, and recovers before anyone notices something broke.

My current obsession is at the intersection of **platform engineering** and **LLM agents**: using tools like Claude Code, MCP, and the OpenAI Agents SDK to build systems that don't just run workloads — they understand them.

---

## What I Work On

**Infrastructure & Automation** — Kubernetes clusters, Terraform-managed cloud, Ansible playbooks, and CI/CD pipelines in Jenkins and GitHub Actions that go from commit to production with zero manual gates.

**Agentic AI Systems** — building agents that interact with real infrastructure: LLMs connected to live tools via MCP, autonomous debugging workflows with Claude Code, and multi-agent pipelines using the OpenAI Agents SDK.

**AI-Powered Observability** *(current project)* — an intelligent logging and monitoring platform where LLM agents parse distributed system logs, correlate anomalies across services, and surface root causes — replacing alert fatigue with actionable intelligence.
